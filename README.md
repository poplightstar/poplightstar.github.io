# Exam calendar 2026/27

Every test, coursework deadline and presentation for the year, by teaching week.

- `index.html` is the page (served by GitHub Pages).
- `exams-2026-27.ics` imports the dated tests into Apple or Google Calendar, with reminders 7 days and 2 days before.
- `events.json` is the source data. Items with `"tbc": true` only have a week, not a day yet.
